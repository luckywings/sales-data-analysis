# 📊 Sales Data Analysis

## 📌 Project Overview

This project analyzes sales data to identify sales trends, top-performing products, regions, and overall business performance.

## 🛠️ Tools Used

- Microsoft Excel
- SQL
- Python
- Pandas
- Power BI

## 🎯 Objectives

- Analyze total sales and profit
- Identify top-performing products
- Compare regional performance
- Find monthly sales trends
- Generate useful business insights

## 📈 Key Analysis

The project will include data cleaning, exploratory analysis, visualizations, and an interactive dashboard.
